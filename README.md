# cyberguard-security-system


CyberGuard is a beginner-friendly Python security analysis tool designed to evaluate user account safety, detect potential brute-force attacks, and generate an automated security report.


1.Account Status Verification:Checks whether an account is currently active or inactive.

2.Brute-Force Detection:** Flags accounts with excessive failed login attempts.

3.Password Strength Assessment:Evaluates password length to identify weak credentials.

4.Risk Scoring:Calculates a dynamic numerical risk score and compares it against a user-defined threshold.

5.Data Type Auditing:Uses Python's `type()` function to verify data integrity during execution.

Python Concepts Applied
•Variables and clean naming conventions

•Core data types (`str`, `int`, `float`, `bool`)

•User input and console output (`input()`, `print()`)

•Explicit type casting (`int()`, `float()`, `str()`)

•Comparison and logical operators

•Conditional branching (`if` / `else` statements)


1. Make sure you have Python 3 installed on your computer.

2. Clone this repository or download `cyberguard.py`.

3. Open your terminal or command prompt and run:
   ```bash
   python cyberguard.py
   ```
4. Follow the on-screen prompts to test different account scenarios.
